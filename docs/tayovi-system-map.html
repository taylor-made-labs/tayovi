Core product picture

A2UI is the engine.

Tayovi wraps A2UI with the smallest missing contract. It does not replace A2UI, build another renderer, or turn Mira into the main product.

What each foundation owns

Each responsibility has one home. Reusing A2UI and MCP keeps the suite focused.

A2UI

The interface engine doing most product work.

  • Catalogs and component schemas
  • Surfaces, streaming, and rendering
  • Bindings, actions, and functions
  • Validation and accessibility

MCP

Machine interface for agents.

  • Typed tools
  • Readable resources
  • Structured results
  • Change notifications

browser-repos

Browser-local Git workspaces.

  • Multiple repositories
  • Commits and diffs
  • History and recovery
  • Remote synchronization

Tayovi

A thin OpenAPI-inspired contract and personalization lifecycle around A2UI.

  • App-defined invariants and policy
  • Base identity and personal fork rules
  • User-owned deltas
  • Preview, apply, persistence, and undo

Mira

Minimal dogfood host, never the product center.

  • Only the approved starter
  • Board and item details
  • Human-agent parity
  • Tracer proof for Tayovi

Contracts

Cross-repository agreement.

  • Versioned schemas
  • Provider promises
  • Compatibility ranges
  • Independent checks
